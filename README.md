# Proteus Projects

Electrical Engineering coursework projects simulated in Proteus 8, including digital counters and power circuits.

## Projects

### 4-bit T Counter
A 4-bit counter built from four JK flip-flops wired as T flip-flops, with AND and NOT gates for the toggle logic. A 7447 decoder drives a 7-segment display.

File: `4bitTcounter Project.pdsprj`

## Tools
Proteus 8 (open the .pdsprj files with Proteus 8 or later)
